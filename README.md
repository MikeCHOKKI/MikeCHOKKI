## `$ cat about.md`

Je construis des **infrastructures numériques souveraines pour l'Afrique de l'Ouest** : des produits qui tournent sur les serveurs de leurs propriétaires, se paient en FCFA et se supportent en français.

Côté technique, j'associe la performance de **Go** pour les services concurrents, la rigueur de **Spring Boot** pour les systèmes transactionnels, et **Laravel / React** pour livrer vite des produits utilisables : quatre plateformes LucidForge tournent aujourd'hui en production sur cette pile. Basé entre **Dakar** et **Cotonou**.
